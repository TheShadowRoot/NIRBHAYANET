A Community-Powered Women's Safety Ecosystem

About the Project

NIRBHAYANET is a technology-driven women's safety platform designed to bring essential safety features together within a unified digital ecosystem. The project aims to make safety-related resources more accessible by connecting journey safety, trusted contacts, community assistance, emergency alerts, and safe-place information through a user-friendly interface.

The platform focuses on empowering women with accessible digital safety tools while encouraging responsible community participation. It is designed to complement existing emergency services rather than replace them.

Key Features

- SOS Alerts: Supports emergency alert management.
- Journey Safety: Organizes journey information and check-in records.
- Trusted Contacts: Supports the management of trusted-contact information.
- Community Assistance: Provides a system for submitting community help requests.
- Volunteer Applications: Supports volunteer applications and related verification records.
- Safe Places: Organizes information about designated safe places.
- Safety Reporting: Enables the recording of community safety concerns.
- Rewards and Recognition: Supports reward and points management.

Feature availability depends on the current implementation status of the project.

System Architecture

NIRBHAYANET uses a React-based frontend connected to Supabase services, with PostgreSQL serving as the relational database.

The architecture separates the user interface from data storage and uses configured database permissions and Row Level Security policies to control access to application data.

Database Design

The database consists of 14 application-specific tables designed to organize information related to user profiles, organisations, volunteer applications, help requests, verification records, SOS alerts, journeys, check-ins, trusted contacts, safety reports, safe places, rewards, and administrative activities.

Security and Privacy

Security and privacy are important considerations in NIRBHAYANET because the platform may handle personal and journey-related information.

The project uses Supabase Row Level Security (RLS) as a mechanism for restricting database access. Appropriate policies, secure configuration, and testing are necessary to protect sensitive information.
