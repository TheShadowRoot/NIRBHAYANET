# NIRBHAYANET 🛡️
> **Protect. Connect. Recognize.**  
*A Community-Powered Women's Safety Ecosystem*

---

## 📌 About The Project
NIRBHAYANET is a technology-driven women's safety platform designed to connect emergency support, safer journeys, verified community assistance, and trusted public spaces into one coordinated ecosystem.

It provides a complementary community-support layer connecting local organizations, participating safe places, verified volunteers, and users through a secure digital platform.

---

## ✨ Core Features & Modules
* 🚨 **Emergency SOS & Helpline Access:** Instant alert triggers and automated emergency system notifications.
* 🛡️ **Smart Journey Guardian:** Route risk assessment and deviation/anomaly detection.
* 🤝 **Nearby Help Network:** Geolocation-based assistance from verified community volunteers.
* 🏢 **Safe Places Network:** Directory and navigation to verified safe havens.
* 🏆 **Good Samaritan Rewards:** Recognition system for responsible community contributors.
* 📊 **Admin & Partner Dashboard:** Verification and monitoring dashboard for local authorities and partners.
